# Triage labels

Use this mapping when a skill assigns a triage role to a GitHub issue.

| Canonical role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer needs to evaluate the issue. |
| `needs-info` | `needs-info` | More information is needed from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The issue is fully specified for an agent to implement. |
| `ready-for-human` | `ready-for-human` | The issue requires a human to implement. |
| `wontfix` | `wontfix` | The issue is closed without a planned fix. |

Edit the GitHub label column when this repo's label names change.
